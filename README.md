# نظام جرد عيادات الأسنان — حسابات مستقلة + مخزن مخصص + واتساب تلقائي

## المميزات

### 🏥 1. حساب مستقل لكل عيادة (متعدد العيادات)
- إنشاء حساب خاص لكل عيادة (اسم العيادة + اسم مستخدم + كلمة مرور).
- كل عيادة ترى **بياناتها فقط**: المواد، الموردين، المخزن، إعدادات واتساب — باستقلالية كاملة.
- وضعان للتشغيل:
  - **وضع الخادم** (`npm start`): الحسابات محفوظة في الخادم (`data/`) وتعمل من أي جهاز/متصفح.
  - **الوضع المحلي** (فتح `index.html` مباشرة أو استضافة ثابتة): حسابات مستقلة على نفس الجهاز/المتصفح.
- إدارة الحساب: تعديل بيانات العيادة، تغيير كلمة المرور، حذف الحساب، تسجيل خروج.
- البيانات القديمة (قبل الحسابات) تُنقل تلقائياً لأول حساب يُنشأ على نفس المتصفح.

### 🎨 2. مخزن مخصص لكل عيادة (رفع صورة + تحديد الجرارات)
- من زر **🎨 مخزني**: ارفع صورة الخزانة/المخزن الحقيقي في عيادتك.
- ارسم مناطق الجرارات والخزائن **على صورتك** بالسحب (وضع الإضافة)، ثم:
  - اسحب أي منطقة لنقلها، واسحب النقطة الزرقاء لتغيير حجمها.
  - عدّل الاسم والنوع (🗄️ جرار / 🚪 خزانة) من اللوحة الجانبية أو بالنقر المزدوج.
  - ارفع صورة داخلية لكل جرار/خزانة (اختياري).
  - احذف مناطق أو أعد التصميم الافتراضي (المواد محفوظة).
- الشاشة الرئيسية تعرض صورة مخزنك ومناطقك مباشرة.

### 📱 3. واتساب تلقائي عند الحد الأدنى
- ربط رقم واتساب العيادة ومنحه صلاحية الإرسال (وضعان):
  1. **wa.me العادي** (مجاني): عند وصول مادة للحد الأدنى يظهر تنبيه فوري بزر واحد يفتح محادثة المورد المعتمد برسالة جاهزة.
  2. **Cloud API التلقائي الكامل**: إرسال تلقائي 100% بدون أي تدخل عند تفعيل «تفعيل تلقائي» وتعطيل «تأكيد قبل الإرسال».
- **محرك مراقبة مستمر**: يفحص كل تغيير في الكميات (من أي شاشة) ويرسل للمورد المعتمد للمادة تلقائياً.
- **منع التكرار**: لا تُعاد نفس الرسالة قبل مدة «إعادة التنبيه» (ساعة/6 ساعات/24 ساعة/أسبوع) إلا إذا تغيرت الكمية.
- **سجل إرسال** داخل إعدادات واتساب (ناجح/فاشل + الوقت + ID الرسالة).
- قالب رسالة يدعم: `{repName}` `{companyName}` `{itemsList}` `{date}` `{clinicName}`.
- عند التشغيل عبر الخادم (`npm start`) يتم إرسال Cloud API عبر **وسيط داخلي** — بدون مشاكل CORS.

### 📦 مميزات الجرد الأساسية
- إضافة مواد بصور، حد تنبيه لكل مادة، تفعيل «واتساب تلقائي» لكل مادة.
- إدارة موردين مع أرقام هواتف وواتساب، وربط كل مادة بموردها المعتمد.
- تقارير، تصدير/استيراد نسخة احتياطية لكل عيادة، تنبيهات انتهاء الصلاحية.

## طريقة التشغيل

### الخيار 1: خادم العيادات (موصى به — حسابات مشتركة بين الأجهزة)
```bash
npm start
# ثم افتح: http://localhost:3000
```
- يتطلب Node.js 18+ فقط، **بدون أي مكتبات خارجية**.
- الحسابات والبيانات تُحفظ في مجلد `data/` (مُتجاهل من Git).

### الخيار 2: وضع محلي (بدون خادم)
- افتح `index.html` في المتصفح مباشرة (Chrome يفضل)، أو أي استضافة ثابتة.
- الحسابات مستقلة على نفس الجهاز/المتصفح.

## النشر على Render
- **كموقع ثابت**: New → Static Site — يعمل بالوضع المحلي (حسابات لكل جهاز).
- **كخادم Node.js** (للحسابات المشتركة + وسيط واتساب): New → Web Service:
  - Build Command: `npm install && npm run build`
  - Start Command: `npm start`
- ملاحظة: نظام ملفات Render المجاني قد يفقد مجلد `data/` عند إعادة النشر — صدّر نسخاً احتياطية دورياً من زر 💾 تصدير.

## ربط واتساب Business API (تفاصيل)
راجع `WHATSAPP_SETUP_GUIDE.md` — خطوة بخطوة للوضعين + شرح الإرسال التلقائي.

## الملفات
- `index.html`: البرنامج الرئيسي (حسابات + مصمم مخزن + جرد + واتساب).
- `server.js`: خادم الحسابات والبيانات ووسيط واتساب (بدون مكتبات).
- `data/`: بيانات الخادم (تُنشأ تلقائياً، خارج Git).
- `images/full.jpg`: صورة المخزن الافتراضية.
- `images/drawer.jpg` / `images/cabinet.jpg`: صور افتراضية داخل الجرارات/الخزائن.

## البيانات
- وضع الخادم: `data/users.json` + `data/clinics/<id>.json` (كلمات المرور مشفرة scrypt).
- الوضع المحلي: `localStorage` بمفتاح مستقل لكل عيادة + مفتاح الحسابات.
- زر 💾 تصدير يصدّر نسخة العيادة الحالية (شاملة صورة المخزن والمناطق).
