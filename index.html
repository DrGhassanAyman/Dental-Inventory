🔧 إعدادات WhatsApp Cloud API - للإرسال التلقائي الكامل

📚 كيف تحصل على البيانات؟

1. ادخل developers.facebook.com → إنشاء تطبيق → نوع Business → إضافة منتج WhatsApp
2. من لوحة التحكم → WhatsApp → API Setup → انسخ Phone Number ID و Access Token
3. الصقها هنا. دليل مفصل

⚠️ Token يُحفظ محلياً في متصفحك فقط - لا يُرسل لأي خادم خارجي

POST https://graph.facebook.com/v20.0/{phone-number-id}/messages Headers: Authorization: Bearer {token} Body: {"messaging_product":"whatsapp","to":"9627...","type":"text","text":{"body":"..."}}

🤖 الإرسال التلقائي عند الحد الأدنى — كيف يعمل؟

عند تفعيل «تفعيل تلقائي» بالأعلى، يراقب النظام الكميات باستمرار: أي مادة مفعّل لها «واتساب تلقائي» ووصلت للحد الأدنى تُرسل رسالة تلقائية للمورد المعتمد لها — عبر Cloud API بدون أي تدخل (إذا عطّلت «تأكيد قبل الإرسال»)، أو عبر wa.me بضغطة واحدة من التنبيه (المتصفح يمنع الفتح التلقائي الكامل بدون ضغطة). لن تُعاد نفس الرسالة قبل مدة «إعادة التنبيه» إلا إذا تغيرت الكمية.
